# Bangladesh CivicOS — Frontend Demo

This is a complete static frontend prototype based on the uploaded Bangladesh CivicOS project report.

## Stack
- HTML
- CSS
- Vanilla JavaScript

## Open
Start with `index.html`.

## Demo pages
- Citizen: citizen/dashboard.html
- Department Manager: manager/dashboard.html
- Field Officer: officer/dashboard.html
- Supervisor: supervisor/dashboard.html
- System Admin: admin/dashboard.html

## Notes
This is frontend-only. Forms and action buttons use demo interactions; PHP/MySQL authentication, CRUD, file upload persistence, real GPS/maps, notifications, and database integration are not implemented yet.
